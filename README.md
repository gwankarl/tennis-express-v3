# Tennis Xpress

Tennis Xpress is a lawn tennis equipment marketplace launching in Yaoundé, Cameroon. Buyers and sellers share an account; seller access requires approval. The application is a React Router SSR frontend and a versioned Fastify REST API backed by PostgreSQL and Drizzle.

## Prerequisites

Use the repository-pinned runtime:

- Node.js `24.22.2`
- npm `11.19.1`
- Git, PostgreSQL, and Git Bash on Windows

From the repository root, confirm the versions:

```bash
node --version
npm --version
```
